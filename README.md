# temperature-converter
A lightweight Java CLI application that converts Celsius temperatures to Fahrenheit and Kelvin using precise floating-point arithmetic.

# Features
- Accepts user temperature inputs in Celsius via `Scanner`.
- Converts Celsius to Fahrenheit using the formula: `(Celsius * 1.8) + 32`.
- Converts Celsius to Kelvin using the formula: `Celsius + 273.15`.
- Utilizes `Double.valueOf()` to accurately capture and preserve decimal values.

# Concepts Applied
- Primitive and Wrapper Data Types (`double`, `Double`)
- Floating-point arithmetic precision
- String concatenation with proper formatting
- Input stream sanitization
